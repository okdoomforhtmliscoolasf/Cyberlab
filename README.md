# CyberLab

A static, beginner-friendly cybersecurity learning playground built with HTML, CSS and vanilla JavaScript.

## Modules
- Signal spotting: identify suspicious-message warning signs.
- Password basics: local educational password-length demo. Do not enter real passwords.
- Read the logs: review fictional audit events.
- Network basics: interactive concept cards.
- Incident response: safe decision-making scenario.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a repository named `cyberlab`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, `main`, and `/(root)`, then Save.

## Safety
All examples are fictional and run in the browser. This project does not scan, connect to, or test real systems. Never enter real passwords or interact with systems without explicit permission.
